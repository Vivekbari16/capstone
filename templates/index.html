About This Project

Deepfake Detector is a modern web application designed to help users detect manipulated ("deepfake") images using state-of-the-art artificial intelligence. As deepfakes become more sophisticated, ensuring media integrity, security, and public trust is crucial.

Why Deepfake Detection?

Deepfakes can be used to spread misinformation and harm reputations. Our AI-powered detection tools verify the authenticity of digital content, ensuring a safer and more trustworthy online environment.

Technology Stack

Our solution uses Python, HTML, CSS, JavaScript for the frontend, and detection leverages deep learning models such as ResNet, EfficientNet, ConvNet, and Swin Transformer.

Performance Metrics

Achieved 94.7% accuracy in binary classification on benchmark datasets. The model uses 0.75M parameters, with inference time augmentation for optimal and fast results.
